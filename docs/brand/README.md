# QUOTA logo

The full brand guide (colours, fonts, rules) is on the **Brand · QUOTA** page of the [Figma file](https://www.figma.com/design/VlTombwHX1DQ7yB2x4U5Yx).

| File | Use it for |
|---|---|
| `logo/quota-logo.png` | Full logo on light backgrounds (README, slides, documents). Transparent PNG. |
| `logo/quota-logo-on-dark.png` | Full logo on dark backgrounds. Transparent PNG. |
| `logo/quota-mark.svg` / `quota-mark.png` | The Q mark alone, when space is short. SVG scales to any size. |
| `logo/quota-mark-on-dark.svg` | The Q mark on dark backgrounds. |
| `logo/quota-app-icon.svg` / `quota-app-icon-512.png` | App icon, Docker Hub avatar, GitHub social preview. |
| `logo/favicon-32.png` | Browser tab icon for the React client (`client/public/`). |

**Rules:** keep space of half the mark around the logo; do not recolour or stretch it; the red-white-red trail blaze stays red-white-red.

**Colours:** pine `#1D4A3A`, dark pine `#0E2019`, snow `#F3F6F4`, blaze red `#E0352B` (brand only, never for errors).
**Font of the name:** Barlow Condensed Bold, letter-spacing 8 % (free on Google Fonts).
